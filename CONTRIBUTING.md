# Contributing to FlowLens

Thanks for helping improve FlowLens.

## Development

Requirements:

- Node.js 20 or newer
- npm

Setup:

```bash
npm install
npm run build
npm test
```

## Pull requests

1. Keep changes focused on one problem or feature.
2. Add or update tests when behavior changes.
3. Update documentation when CLI behavior changes.
4. Run `npm run check` before opening a pull request.
5. Use a clear commit and pull request description.

## Ideas

For new features, please open an issue first so the design can be discussed before implementation.
