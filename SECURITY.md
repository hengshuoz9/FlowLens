# Security Policy

## Supported versions

Only the latest version on the `main` branch is actively maintained during the early development phase.

## Reporting a vulnerability

Please do not disclose security vulnerabilities in a public issue.

Open a private security advisory through GitHub, or contact the repository owner privately with:

- a clear description of the issue
- affected versions or commits
- reproduction steps or a minimal proof of concept
- the potential impact

Please avoid including secrets, personal data, or unrelated third-party information.
