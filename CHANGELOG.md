# Changelog

All notable changes to FlowLens will be documented here.

## 0.1.0 - 2026-09-09

### Added

- HTTP health checks for websites and APIs
- GET and HEAD methods
- Response latency measurement
- Redirect tracking with a safety limit
- Timeout handling
- Human-readable CLI reports
- JSON output for automation
- Optional response headers
- Non-zero exit codes for CI usage
- TypeScript source and Node.js test coverage
- GitHub Actions CI across Node.js 20, 22, and 24
